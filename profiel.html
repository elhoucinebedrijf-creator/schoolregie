Tweestapsverificatie (2FA)

Bezig met laden…

Beveilig je account met een authenticator-app (bv. Google Authenticator, Authy, 1Password) - bij inloggen wordt dan naast je wachtwoord ook een 6-cijferige code gevraagd.

Scan deze QR-code met je authenticator-app, of voer de code handmatig in.

2FA is actief op je account.
