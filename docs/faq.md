# Veelgestelde vragen

**Waarom moet ik 2FA instellen om in te loggen?**
Dit is verplicht voor de rollen administrator en directie, vanwege de
gevoelige leerling-/personeelsgegevens die zij kunnen inzien. Andere
rollen kunnen dit optioneel instellen onder **Profiel**.

**Ik zie een status-tijdlijn op een gemiste toets — wat is dat?**
Elke wijziging van de status van een dossier (bv. van "nieuw" naar
"gepland" naar "afgerond") wordt vastgelegd, inclusief wie de wijziging
deed en wanneer. Zo is altijd te herleiden hoe een dossier tot zijn
huidige status is gekomen.

**Wat gebeurt er als ik een leerling archiveer?**
De leerling verdwijnt uit de reguliere lijsten, maar de gegevens blijven
bewaard — archiveren is geen verwijdering. Alleen een administrator kan
dit doen, per leerling, nooit automatisch in bulk.

**Hoe corrigeer ik een fout in een geïmporteerd bestand?**
Herimporteer het gecorrigeerde bestand — bestaande rijen worden
bijgewerkt op basis van dezelfde matching als de eerste import (meestal
e-mailadres of naam), niet gedupliceerd.

**Is er een limiet op hoe vaak ik acties kan uitvoeren?**
Ja, uit voorzorg tegen misbruik/fouten is er een korte-termijn limiet,
vooral op de publieke bevestigingslinks (oudergesprek/OPP) die zonder
inloggen werken. Bij normaal gebruik merk je hier niets van.
